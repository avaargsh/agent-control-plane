Execute · ACP-owned

Execute — 执行决策

支付记录匹配后，由 ACP 决定是否执行任务；Ledger 本身从不执行、不调度、不重试。

Prove · SHA-256

Prove — 证据锚点

证据字节重新哈希，与链上锚点的 Evidence digest 比对；匹配即 EvidenceAnchored，仅证明摘要一致。

状态机：每一步都是可读观察

不确定时保持 PaymentUnknown，矛盾时标记 Conflict，绝不自动充值。

Created
ACP 声明 NotStarted，链上 Created
未知任何授权的支出；Ledger 自身从不授权。
PaymentUnknown
首次授权的 x402 尝试已预留
结果不确定 ≠ 支付失败；不自动充值，不重发签名。
PaymentObserved
独立验证的 Transfer + AuthorizationUsed nonce
等待链上可信记录器确认匹配。
PaymentRecorded
记录器链上 Paid 与观察到的事件匹配
执行结果仍由 ACP 拥有。
EvidenceAnchored
证据字节 SHA-256 与链上 anchor 匹配
仅证明摘要一致，不证明执行正确。
