# AgentOS v3.2 OPA Enforcement Proof

This experiment validates the Policy Projection boundary with a real OPA binary.

The control plane compiles portable CapabilityIntent into Rego v1. OPA performs
the decision. The control plane does not embed an authorization evaluator.

The CI proof uses OPA v1.21.0 and asserts:

- `filesystem.read /var/log/app.log` -> allow;
- `filesystem.read ~/.aws/credentials` -> deny;
- `network.egress evil.example` -> deny;
- `kubernetes.mutate delete deployments` -> deny.

The generated policy digest is emitted as an artifact-friendly value so runtime
Evidence can bind an authorization decision to the exact compiled policy.

```text
CapabilityIntent
      |
      v
OPA compiler
      |
      +--> policy.rego
      |
      +--> sha256 policy digest
      |
      v
OPA v1.21.0
      |
      +--> allow
      +--> deny
```

Reasoning may propose an action. OPA remains the deterministic enforcement
boundary.
