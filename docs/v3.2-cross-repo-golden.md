# AgentOS v3.2 Cross-Repository Golden Slice

This is the first v3.2 proof where the control plane and runtime no longer use
independent policy/evidence fixtures.

The workflow pins a concrete `cloud-agent-runtime` commit and proves one
provenance chain end to end:

```text
CapabilityIntent
      |
      v
agent-control-plane
      |
      +--> Rego v1
      |
      +--> sha256(policy.rego)
      |
      v
OPA v1.21.0
      |
      +--> real allow / deny decisions
      |
      v
AGENTOS_POLICY_DIGEST
      |
      v
cloud-agent-runtime
      |
      v
Temporal Workflow
      |
      v
Kubernetes Sandbox A -- real loss --> Sandbox B
      |
      v
OTel span
      |
      | agent.policy.digest = exact compiled digest
      v
EvidenceEvent
      |
      v
content-addressed Evidence object + manifest
      |
      v
replay
      |
      v
Temporal terminal result
```

## Pinned runtime

The workflow pins:

```text
cloud-agent-runtime
8dafeb1e8ec5f91e9b2ee7d787903f9ff0b0d401
```

It intentionally does not follow `runtime/main`. A successful proof therefore
identifies the exact runtime implementation that consumed the policy artifact.

## Required invariants

The job fails unless all of the following hold:

1. the digest emitted by the control-plane compiler equals the SHA-256 digest of
   the generated `policy.rego`;
2. real OPA evaluates the expected allow and deny cases;
3. the runtime accepts exactly that digest as `AGENTOS_POLICY_DIGEST`;
4. the OTel Evidence projection carries the exact digest;
5. object-manifest replay returns the exact digest;
6. Temporal completion carries the exact digest;
7. Run, Session, and Temporal workflow identity survive real Kubernetes sandbox
   replacement;
8. Sandbox identity changes and the old Pod converges to deletion.

## Boundary

This is provenance binding, not runtime coupling.

- AgentOS still owns portable intent and release governance.
- OPA still owns policy evaluation.
- Temporal still owns durable waiting/workflow execution.
- Kubernetes sandbox providers still own execution isolation.
- Object storage still owns evidence retention/immutability enforcement.

The cross-repository CI merely proves that the contracts compose without
inventing another runtime or authorization layer.
