# v0.1.0 Public Compatibility Surface

The machine-readable compatibility snapshot is
[`release/v0.1-public-contract.json`](../release/v0.1-public-contract.json).
Run:

```bash
python scripts/verify_v01_public_contract.py
```

The v0.1.0 compatibility promise is intentionally explicit and narrow.

## Stable in v0.1.0

### Installed console scripts

- `agent-control-plane`
- `agent-context-mcp`

### `agent-control-plane` command names

- `validate`
- `plan`
- `gate`
- `authority-inventory`
- `authority-admit`
- `decision-eval-verify`
- `decision-eval-gate`
- `live-proof-verify`

The command names are stable for v0.1.0. This contract does not claim every
error string or help-text sentence is a stable API.

### Top-level Python exports

The names exported through `agent_control_plane.__all__` are snapshotted in
the machine-readable contract. The three exported authority dataclasses also
have their field order/names checked:

- `AuthorityGrant`
- `AuthorityDiff`
- `AuthorityAdmissionDecision`

### Manifest schemas

The supported manifest kind-to-schema mapping in
`agent_control_plane.validator` is snapshotted. All mapped schema files must
be present in both source checkouts and built wheels.

### IndependentExecutionProof

The v0.1 completed-execution proof wire identity is stable:

```text
predicate_type    = agent-control-plane/state-transition-execution/v1
statement_version = independent-execution-proof/v1
```

Stable top-level fields:

```text
proof_id
subject
predicate_type
predicate
statement_hash
statement_version
```

Stable predicate members:

```text
transition_plan
plan_authorization
plan_fence
execution_attempt
after_observation
verification_report
```

The full acceptance semantics are defined in
[`V0.1_ACCEPTANCE_ARTIFACT_CONTRACT.md`](V0.1_ACCEPTANCE_ARTIFACT_CONTRACT.md).

## Not promoted to public compatibility

The following remain implementation details in v0.1.0:

- SQLite table layouts and migration internals;
- Kubernetes/GitHub provider-adapter class APIs;
- lifecycle coordinator implementation classes;
- test fixtures and fault-injection helpers;
- internal module-private constants/functions;
- exact logging/error-message wording;
- synthetic Golden Incident fixture payload shapes unless separately covered by
  a manifest schema.

This boundary prevents accidental promises. A source-level Python object being
importable does not by itself make it a supported public API.

## Compatibility rule

A change that alters the machine-readable snapshot must not be merged into a
v0.1.0 release candidate silently. It requires one of:

1. restoration of the v0.1 contract;
2. an explicitly versioned compatibility decision;
3. deferral to a post-v0.1 release.

The release verifier runs this check before packaging.
