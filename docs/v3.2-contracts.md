# AgentOS v3.2 Contract Baseline

AgentOS stays a thin control plane. v3.2 freezes four implementation gaps only:

1. Binding
2. Policy Projection
3. Evidence Provenance
4. Execution Contract

The control plane does not become a durable workflow runtime, sandbox runtime, vector-memory product, or universal agent RPC.

## Contract boundary

- RuntimeBinding binds Run, Session and Release identities to provider capabilities and recovery policy.
- SandboxBinding makes sandbox identity replaceable while Run and Session identity and durable state references survive.
- CapabilityIntent is portable desired authorization. policy_projection.py is the deterministic compiler seam for OpenShell, OPA, NetworkPolicy, MCP capability and credential lease targets.
- EvidenceEvent is authored outside the harness and requires generated_by, observed_by, authorized_by, executed_by and committed_by.
- ToolContract carries effect, idempotency, retry, verification and compensation semantics.
- AgentRelease can freeze CapabilityIntent references and evidence requirements.

## Executable acceptance slices

Evidence provenance:

## Next integration step

Replace deterministic reference seams with real providers without changing the contract:

- CapabilityIntent to OpenShell, OPA, Kubernetes NetworkPolicy, MCP capability enforcement and credential leases.
- SandboxBinding to Temporal workflow plus Kubernetes Agent Sandbox checkpoint and rebind.
- EvidenceEvent to Agent Gateway, Tool Proxy and Sandbox Supervisor collectors backed by append-only storage.
- ToolContract to MCP schema extension and a fault-injected deploy tool.
